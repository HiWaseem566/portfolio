FINAL YEAR PROJECT

Machine Learning-Based Battery Health Assessment System

For my Final Year Project, I developed a machine learning-based system to assess the health of lead-acid batteries by analyzing current, voltage, and temperature data. This project enabled predictive maintenance by identifying battery degradation in real time.

Developed a smart system to predict the State of Health (SOH) of lead-acid batteries using real-time sensor data and machine learning. The system used multiple sensors including:

  • Current Sensor (ACS712) – to measure battery current
  • Voltage Divider Circuit – to monitor voltage levels
  • Temperature Sensor (LM35) – to detect temperature variations

An ESP32 microcontroller was used for sensor data collection and wireless communication. The data was processed and sent to a trained machine learning model to analyze battery condition and predict degradation patterns.
